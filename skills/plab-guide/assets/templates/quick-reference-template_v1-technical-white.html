This is the v1.5 quick-reference template. Each card below demonstrates one layout pattern with sample content. Replace samples with topic-specific operator content while preserving structure. Card classes: default (white) for action / narrative; .ref (tinted left rule) for lookup / reference; .diagram for inline Mermaid SVG; .span-6 .summary for a closing full-width banner. .span-6 on any card promotes it to full-row width. Target density: 1-2 dense pages with auto-fit, 6.75pt body at 1.22 line-height, ink ratio >= 0.30 per page. Author enough cards to fill the space; the renderer auto-fits a slight overflow back to 2 pages.

Step-Row Pattern ordered

1.first-step / brief description after slash.
2.second-step / each row alternates background.
3.third-step / keep descriptions short.
4.fourth-step / target ~60 chars per line.
5.fifth-step / arrows ok: A → B → C.
6.sixth-step / final action.
Use for: sequential workflows, ordered processes, pipelines, lifecycles. Numbers in mono blue; bold lead term + slash + description.

Bullet List principles

  • Lead term. Short sentence after the bold.
  • Another principle. Keep each line on a single visual row.
  • Third point. Aim for 4-6 items.
  • Fourth. Bullets are good for unordered values, principles, or do-this lists.
  • Fifth. Avoid nested lists; flatten if possible.
Use for: principles, philosophies, unordered short items where order is not significant.

Diagram (Vertical) .diagram span-3

```mermaid flowchart TD A[Input] --> B{Validate} B -->|ok| C[Process] B -->|fail| D[Reject] C --> E[Persist] E --> F[Done] D --> F ```
Use for: portrait / vertical diagrams (state machines, top-down decision flows). Single-column width; max-height 1.8in. Mermaid source is replaced by inline SVG in Phase 6.5.

Summary Banner .span-6 .summary

This card spans the full row across both columns and carries a top accent rule. Use as a closing callout, "the rule" callout, or key takeaway. One per page maximum so it remains visually prominent.

When to use: bottom-of-page summary, license + author block, pull quote that synthesizes the page's content into one sentence.

Diagram (Horizontal) .diagram .span-6

```mermaid flowchart LR Author[Author] --> Stage[Stage] Stage --> Commit[Commit] Commit --> Push[Push] Push --> Review[Review] Review --> Merge[Merge] Merge --> Deploy[Deploy] ```
Use for: landscape / horizontal diagrams (pipelines, sequence diagrams with many participants, ER diagrams). .span-6 promotes to full-row width; max-height 2.2in (vs 1.8in for vertical). Reading order shifts to left-to-right.

Code Block Pattern pre

Single command

cli command --flag value

Multi-line command

cli command \
  --flag value \
  --other-flag

With syntax tokens

cli primary-arg --flag value
# inline comment in muted gray
Use for: shell commands, scripts, install snippets. <span class="k"> for keywords/values; <span class="c"> for comments. Auto-wrap on long lines.

Recipe Pattern mixed

Lead paragraph introduces the recipe in 1-2 sentences. Code blocks or tables follow.

cmd-one --setup
cmd-two --run
# the recipe ends here

Closing paragraph if needed. Reference an action with follow-up-cmd.

.aside element: italic, blue left border, light tint. Use for clarifying notes, footnotes, or nuance the body skips.
Use for: recipes (intro + commands + close + nuance), worked examples, multi-element walkthroughs.
